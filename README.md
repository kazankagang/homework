# Домашние задания группы

Статический сайт для GitHub Pages. Сервер и база данных не нужны.

## Как опубликовать

1. Создайте репозиторий на GitHub (например, `homework`), публичный.
2. Загрузите в него все файлы: `index.html`, `style.css`, `app.js`, `homework.json`, `README.md`
   (кнопка **Add file → Upload files**).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/homework/`.

## Как добавить задание

Все задания лежат в файле `homework.json`. Откройте его в репозитории на GitHub, нажмите значок карандаша (Edit),
добавьте блок в список `assignments` и нажмите **Commit changes**. Сайт обновится через минуту.

```json
{
  "subject": "Физика",
  "title": "Задачи по механике",
  "description": "Параграф 12, задачи 1–8.",
  "assigned": "2026-10-09",
  "deadline": "2026-10-16",
  "links": [
    { "title": "Учебник", "url": "https://example.com/book" }
  ]
}
```

Поля `description` и `links` необязательные. Даты пишутся в формате `ГГГГ-ММ-ДД`.
Между блоками обязательна запятая, после последнего блока запятой быть не должно.

Чтобы одногруппники тоже могли добавлять задания, добавьте их в репозиторий:
**Settings → Collaborators**.

## Локальный просмотр

```
python -m http.server
```

Затем откройте http://localhost:8000
